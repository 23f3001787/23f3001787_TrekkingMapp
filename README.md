# Trekking Management Application

A role based web application for adventure organizations to manage trekking activities. Built for MAD-1 iitm project.

## Roles
- **Admin:** to manage treks, staff, and views all bookings.
- **Trek Staff:** to manage assigned treks and participant lists.
- **User (Trekker):** browses ,books and tracks trekking history.
